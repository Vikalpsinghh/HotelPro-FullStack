# HotelPro - MERN Stack Hotel Management App

A full-stack web application built for hotel bookings and front-desk property management. It allows guests to view and book luxury suites while giving hotel staff an admin panel to manage reservations and check-in/out times in real time.

## Live Links
- Frontend: https://hotel-pro-full-stack-ywg2.vercel.app/
- Backend API: https://hotelpro-fullstack.onrender.com

## What It Does
- Room Browsing: Filter rooms by type (Presidential Suite, Executive, Deluxe, Standard).
- Booking System: Reserve suites with dynamic date selection and pricing in INR (₹).
- Admin PMS: Front-desk dashboard to view all active bookings.
- Status Updates: Manage guest lifecycle with 1-click Check-In, Check-Out, and Cancel buttons.
- Audit Timestamps: Tracks and saves exact check-in and check-out times.

## Tech Stack
- Frontend: React, CSS
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Hosting: Vercel (Frontend), Render (Backend)
