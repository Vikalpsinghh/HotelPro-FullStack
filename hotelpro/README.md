# HotelPro - Complete Hotel Booking & Management Solution (MERN)

A complete Full Stack MERN application for managing hotel room inventory, live date reservations, front-desk check-in/out workflows, and housekeeping management.

## Project Structure
- `backend/`: Express.js, Node.js, and MongoDB Mongoose API models & routes.
- `frontend/`: React.js modern UI with responsive guest reservation and front desk PMS screens.

## Quick Start Instructions

### 1. Backend Setup
```bash
cd backend
npm install
npm run dev
```
*(Backend runs on `http://localhost:5000`)*

**Seed Demo Rooms**: Open `http://localhost:5000/api/seed` in your browser once to populate initial rooms.

### 2. Frontend Setup
```bash
cd frontend
npm install
npm start
```
*(Frontend runs on `http://localhost:3000`)*
